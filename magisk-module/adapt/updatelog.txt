# 更新日志（2026-10-20，v1.2.1）

 • 性能优化：前台探测改用 dumpsys window displays，单次系统 CPU 210ms → 70ms（约 1/3）
 • 性能优化：息屏时巡检间隔拉长到 3 倍（息屏不可能有前台游戏），夜间近乎零开销
 • 性能优化：进入游戏时复用 2 秒内的探测结果，不再连续 dump 两次
 • 性能优化：状态改为内存镜像，主循环不再每轮 fork cat；状态没变化就不重写文件
 • 性能优化：频率节点回读改用 read 内建，常态巡检每轮少 10 余次 fork；节点已可写时跳过 chmod
 • 性能优化：policy 列表启动时预计算，风驰调速器检测不再每轮 fork tr/sed
 • 性能优化：WebUI 应用列表缓存 10 分钟（dumpsys package 单次约 4 秒）
 • 性能优化：WebUI 应用图标按包缓存 7 天，并遍历 split APK（微信等分包应用图标不再空白）
 • 兼容性：displays 子命令解析不到焦点时自动退回全量 dumpsys window
 • 兼容性：已在 mksh 下运行时跳过 1 秒的兼容性实测，启动更快
 • 图标修复：新增 bin/apkicon，直接解析 AndroidManifest + resources.arsc 取启动器图标，
   资源混淆的应用（微信、Oplus 相机/游戏中心、腾讯游戏）与自适应图标也能显示真图标
 • 图标修复：优先取小密度图，单张 base64 限制在 120KB 内，避免大图被 WebView 桥截断
 • 应用列表：dumpsys package 结果后台刷新、有缓存直接秒回，首次打开不再卡 5 秒
 • 安装优化：升级不再覆盖 powerd.conf，包内新配置存为 powerd.conf.bak，WebUI「配置」页可一键还原
 • 安装优化：升级时合并旧 games.txt，WebUI 里加的游戏不再随升级丢失
 • 安装优化：已有配置时跳过调速器询问，不会冲掉调好的百分比
 • 稳定性：stop / WebUI 重启会等旧实例真正退出再拉起，避免撞锁后要等看门狗 30 秒

# 更新日志（2026-10-3，v1.2.0）

 • 修复项：频率吸附改为只向下取整，封顶值不再可能超过预期百分比
 • 修复项：chkfreq「上限」列改为显示 scaling_max_freq（真实封顶值）
 • 性能优化：日志时间戳不再 fork date；日志裁剪节流到每 25 次检查一次
 • 性能优化：游戏名单按 mtime 缓存，不再每 5 秒全量重解析；heavy 判定免 grep
 • 稳定性：无可写 GPU 节点时不再空写刷 WARN；启动时检查 awk/timeout/dumpsys
 • 稳定性：调速器快照持久化，kill -9 异常退出后下次启动可恢复
 • 代码优化：抽取 GPU_MIN 复位公共函数，删除无效变量与死分支
 • 新增：README 说明文档 WebUI
